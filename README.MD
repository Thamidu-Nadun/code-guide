# RestAPI Code Style Guides

Welcome to the Luvynta Code Style Guides repository. This collection of documents provides a comprehensive set of coding standards and best practices for various languages and frameworks used in our projects. Adhering to these guidelines helps ensure our code is readable, maintainable, and consistent across all teams.

## Coding Guides

### General

- **[RestAPI](general/RestAPI-GUIDE.MD)**: A guide to develop clean, scalable and well structured API design for large scale application. This covers naming conventions, versioning, return JSON/XML format and more.

### Frameworks

- **[ReactJS](frameworks/ReactJS-CODE-GUIDE.MD)**: A guide to writing clean and maintainable React and JSX code, covering basic rules, naming conventions, and best practices for components, props, and state.

- **[Spring Boot](frameworks/SpringBoot-CODE-GUIDE.MD)**: Standards for developing with the Spring Framework, including file structure, formatting, naming conventions, and programming practices for building robust Java applications.

### Languages

- **[C++](languages/CPP-CODE-GUIDE.MD)**: A comprehensive guide to writing C++ code, focusing on managing complexity and ensuring readability and maintainability.

- **[HTML/CSS](languages/HTML-CSS-CODE-GUIDE.MD)**: Style and formatting rules for creating clean and maintainable HTML and CSS, promoting separation of concerns and semantic markup.

- **[Java](languages/Java-CODE-GUIDE.MD)**: The complete definition of Google's coding standards for Java, covering formatting, naming, and programming practices.

- **[JavaScript](languages/JavaScript-CODE-GUIDE.MD)**: Google's coding standards for JavaScript, focusing on rules for creating readable and maintainable code.

- **[JSON](languages/JSON-GUIDE.MD)**: Guidelines for formatting and structuring JSON, including property naming conventions, data types, and error representation.

- **[Python](languages/Python-CODE-GUIDE.MD)**: A list of dos and don'ts for Python programs, covering everything from linting and imports to naming and type annotations.
